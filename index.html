Cart-Win-Back

AI agent that makes win-back offers · Personal project

An agent that decides which abandoned ticket carts deserve an offer and what to offer. Created for a Provn.com challenge.

THE CHALLENGE

Fans abandon carts daily and nobody follows up. The brief: an agent that decides which stale carts deserve a win-back offer, proposes one with a reason, and puts it in front of a marketer to approve, edit, or reject. Full brief →

TWO VERSIONS BUILT

Two versions of the agent were built in LangGraph. Version 1 has 6 nodes and only used the data provided by the challenge. Version 2 has 10 nodes and fabricated reasonable data a real system could have access to.

WHAT WAS NOT DONE

The agents never went through any form of tuning. This is a proof of concept. And a full review of all AI-generated content hasn't been done. The challenge expected the demo to have AI content.

Dual-Database Inventory Lookup

A dual-database inventory lookup with a web UI and a Claude MCP server · Personal project
View the project →

The company's inventory was split across two systems, Atrex (ElevateDB) and BreezeERP (SQL Server), so there was no single place to check stock, pricing, sales history, or purchase orders. This tool built one.

Two front ends

Runs as a Flask web app in the browser and inside Claude Desktop through an MCP server. The web app shows an inventory card: on-hand, available, on-order, allocated, pricing, plus sub-tabs for sales history, purchase orders, and receiving.

Engineering detail

Shared query logic is reused across the web and MCP servers, with field names normalized so one table renderer handles both systems. The browser version fetches inventory and history in parallel so a slow query doesn't block the card.

AI integration

The MCP server lets an AI assistant query live inventory directly, applying the Claude certification work to a real operational tool.

MTG - The Musical

Real-time reactive music engine · Personal project

An application that listens to a game of Magic: The Gathering in progress and generates reactive music reflecting the colors, themes, and events of the game as it unfolds. Each of MTG's five colors carries a distinct emotional identity that maps to sound design, so game events drive the music in real time.  A Green creature entering should feel ancient and organic; a Red board wipe should feel explosive.

Architecture

The input source and the music engine are separate components connected by an abstract event interface. The input (a digital game client today, a camera-based vision pipeline in a future version) can change without touching the engine.

Stack

C# / .NET 10, with FMOD for layered adaptive audio (pad, rhythm, lead, stingers). Game state is observed over a protobuf protocol; card metadata is resolved against a cached Scryfall dataset.

Status

The adapter, event boundary, and music engine are all built and live-validated. Real card events flowing into audible, reactive audio against a live game. Next steps are tuning the audio and moving it to a web app for a more accessible platform.

Local Multi-Agent System

Agent platform that splits work between local models and Claude · Personal project

Three machines serve local models on a network. A panel shows the status of the cluster: GPU health per machine, the job queue, a live event feed per run, and start/stop control for every service on the controller. A Claude workflow can outsource work to agents on the local network using MCP tools.

LANGCHAIN HARNESS

LangChain provides a framework for building the agentic harness the system runs on. Managing tool calls, context summarization, and agent memory.

Provisioning

One provisioning script installs and joins each machine to the controller. Runners are configured to only take instructions from the controller and within the local network.

Access

Exposed through an MCP server so any Claude session on the controller can reach the agents.

Jammin' Panda

Cross-platform music player · Personal project
View the repo →

A music player built on .NET MAUI for Android and Windows: scans a device's library, plays audio with lock-screen and Bluetooth controls, keeps playlists in SQLite, and downloads YouTube audio straight into the library.

Architecture

A pure-logic Core project has no dependency on the UI or the OS. Anything that touches hardware, like playback or storage, sits behind an interface with a separate implementation per platform.

Stack

Status

Currently in the designing phase. Claude design has been used to create mockups of the front end. A image generator used to make a logo (im not much of an artist). Next steps is to plan out the backend.

05 — STARTUP

ClasScape

An education-technology venture I founded and led.  From a concept to a funded, tested prototype.

Company Goal

ClasScape was a gamification tool for student assessment, built for VR, PC, and Mac. Teachers would create quizzes through a web interface; those questions appeared inside a game, and students earned a short gameplay session afterward, with rewards tied to their performance. The goal was to raise student engagement and retention without adding work for teachers.

My role

Founder and Entrepreneurial Lead. I led a small team and worked with mentors throughout the lifetime of the company. I built the VR assessment demo using Unreal Engine 4 and WordPress. I wrote grants, presented to investors, ran school demonstrations, and performed market research.

Work completed

A functional VR demo, tested in multiple schools and shown at the Innovate MS Accelerate conference. Multiple grants and awards received to fund the project. Product market fit determined through extensive market research.

Why it Ended

The COVID-19 pandemic in early 2020 disrupted in-person school demonstrations and investor confidence. Investor engagement and grant-supported pilot deployments were significantly impacted by this. The startup was unable to sustain momentum, leading to it winding down by January 2022.
